# 📊 Crypto Market Sentiment Trading Analysis

## 🧠 Overview
This project analyzes the relationship between Bitcoin market sentiment (Fear & Greed Index) and trader performance using historical trading data. It helps uncover how emotional market conditions influence trading profitability, risk behavior, leverage usage, and decision-making patterns.

---

## 🎯 Objective
To explore whether market sentiment affects trading outcomes and identify patterns that can help in smarter trading decisions.

---

## 📂 Dataset Used

### 1. Bitcoin Sentiment Dataset
- Columns: Date, Classification (Fear / Greed)

### 2. Hyperliquid Trader Dataset
- Columns: account, symbol, execution price, size, side, time, start position, event, closedPnL, leverage, etc.

---

## ⚙️ Features

- Data loading and preprocessing
- Merging sentiment with trading data
- Profit analysis under Fear vs Greed conditions
- Win rate comparison
- Leverage usage analysis
- Data visualization (graphs)
- Insight generation

---

## 📊 Key Insights

- Comparison of trader profitability during Fear and Greed markets
- Risk-taking behavior under different sentiment conditions
- Win rate variation based on market sentiment
- Leverage usage patterns across market states
